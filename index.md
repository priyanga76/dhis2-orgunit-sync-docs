# DHIS2 Org Unit Sync

Synchronize organisational units between DHIS2 instances safely, accurately, and efficiently.

The DHIS2 Org Unit Sync App helps administrators compare and synchronize organisational units between a source and target DHIS2 instance while maintaining full control over additions, updates, and moves.

---

## Key Features

### 🔗 Secure Connections
- Connect to source and target DHIS2 instances
- Verify user credentials and permissions
- Validate required authorities before synchronization

### 🎯 Flexible Scope Selection
- Filter by organisation unit levels
- Filter by organisation unit groups
- Synchronize only the required subset of organisational units

### 🔍 Intelligent Comparison
- Detect new organisational units
- Identify metadata differences
- Detect organisational unit moves
- Review discrepancies before execution

### 🚀 Controlled Synchronization
- Dry-run validation before execution
- Separate handling of Add, Update, and Move operations
- Detailed execution logs and summaries
- Export results for auditing

### 📊 Audit and Reporting
- Export comparison results
- Export synchronization results
- Maintain an audit trail of operations

## Recommended Workflow

1. Connect to Source and Target DHIS2 instances
2. Verify connectivity and permissions
3. Define synchronization scope
4. Run comparison
5. Review additions, updates, and moves
6. Perform Dry Run
7. Execute synchronization
8. Export results for record keeping
